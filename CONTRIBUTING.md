# Contributing

Install Node.js 22 or 24, run `npm ci`, then `npm test` and `npm run example`. For UI changes, run `npm run browser:install` and `npm run test:browser`.

Open an issue with a reproducible example before a large change. Keep calculations explainable, add a regression test for a bug, update the README and example when behavior changes, and use synthetic customer data. Submit pull requests to main. Contributions are under the MIT license.
